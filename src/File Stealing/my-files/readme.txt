Project Title: Herbal Recognition System

Description:
This project is designed to identify various herbal plants using the YOLOv8 machine learning model. It aims to assist researchers, herbalists, and hobbyists in recognizing and cataloging herbal plants from images.

Installation:

    Clone the repository to your local machine.
    Ensure that Python 3.8 or higher is installed.
    Install the required dependencies by running pip install -r requirements.txt.
    Run the application using the command python app.py.

Usage:
To use the system, simply upload an image of the herbal plant via the GUI. The system will process the image and display the name and details of the recognized plant.
